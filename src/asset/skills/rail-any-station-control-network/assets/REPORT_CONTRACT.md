# 确定性报告契约（2.0）

当前可复现入口为 `scripts/reproduce_project.py`。以下替代旧版仅解释 locked-facts 的限制：

1. 解算器从IN1/IN2独立计算，不读取历史成果初始化坐标；历史结果只用于计算后的比对。
2. 来源清单使用相对路径和SHA-256。输入不允许静默改动，输出不写入来源目录。
3. 固定章节、表头、取位、ZIP时间戳和文档元数据；固定依赖版本，同环境重复生成文件哈希一致。
4. 缺失或非法输入必须报错；数值比对失败保留差异。比对通过不自动代表现行规范合格。
5. Word/Excel/Markdown数据来自同一个result.json对象，完整数值留在JSON，取位只发生在展示层。
6. 尚未验证原始归算、IN3、粗差、接边、历史DOC版式；不同平台的线性代数库和字体需实测。当前只保证已列明的验证范围。
