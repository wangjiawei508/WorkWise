# 平差成果质量检查与成果评定流程

1. 原始数据完整性检查：点号、测站、方向、距离、高差、时间、气象和仪器状态。
2. 平面先独立自由网平差，再用合格起算点约束平差；高程先闭合差检查，再按项目要求平差。
3. 检查单位权中误差、点位中误差、相邻点相对误差、方向/距离残差、环闭合差和附合路线闭合差。
4. 分段网检查重叠点差值；超限先查原始数据、点位稳定性、气象和棱镜，再决定返测或更新。
5. 成果质量检查报告必须逐项给出“指标、实测值、限差、判定、来源引用、处置意见”。

## 研究报告采用的计算链

- 间接平差：`v = A·δx − l`；`N=AᵀPA`；`n=AᵀPl`；解 `N·δx=n`，再计算 `v`、`m₀`、协方差和点位中误差。
- 坐标转换：按项目需要使用高斯投影正反算、二维四参数或三维七参数转换；参数必须来自项目控制资料。
- 三角高程：由斜距、竖直角及仪器/棱镜几何关系求高差，并实施气象、地球曲率和大气折光改正；具体模型须与 TCN DPSA 配置一致。
- 多维粗差同时定位定值：对方向、距离和高差残差联合定位；被识别观测必须回查原始记录并保留修复前后文件。
- 余弦函数加权平滑：用于区段平面、高程和三维坐标接边；窗口与权函数参数必须锁定，禁止由 Agent 自行猜测。

资料中的 `m_s = ±(a+bD)` 仅是仪器测距精度表达式，不是 CPⅢ 网平差公式。
