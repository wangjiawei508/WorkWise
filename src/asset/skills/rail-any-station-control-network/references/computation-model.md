# 计算模型及验证证据

## 来源层次

科研资料描述间接平差、三维平差、粗差、平滑等方法，但已读文本没有给出本工程软件的完整实现。以下为依据测量平差理论、徐望 IN1/IN2 和历史输出重建的模型，不冒称逐字摘自研究报告。技术报告1.4.2、3.3指定中铁二院软件，不能默认是 TCN DPSA。

## 数据

- IN2首行 `0.5,1.0,1.0` 按方向中误差（秒）、固定距离误差（mm）、比例误差（ppm）解释；由双线调权序列和残差验证。
- 已知点行：点号、X、Y（m）；单字段行为测站；L 为方向，S 为水平距离（m）。
- L 是 D.MMSS：11.052853 表示11度05分28.53秒，不能当十进制度。
- IN1已知点：点号、H（m）；观测：起点、终点、高差（m）、距离（km）。
- SUC含斜距和天顶距；不可将斜距直接送入平面模型。IN3为不同五字段格式，当前拒绝用IN1解析器读取。

## 函数与雅可比

测站i、目标j，dx=Xj-Xi，dy=Yj-Yi，d=sqrt(dx²+dy²)，每站一个定向参数omega_i。

L_ij+v_L=atan2(dy,dx)-omega_i

S_ij+v_S=sqrt(dx²+dy²)

控制点和测站的待定坐标共同解算。方向闭合差使用 atan2(sin(delta),cos(delta)) 处理周界。定义 l=观测-f(x0)，v=A delta_x-l。

方向对目标偏导为(-dy/d²,dx/d²)，对测站取反，对omega为-1；乘rho=206264.806247...使方向残差为角秒。距离对目标偏导(dx/d,dy/d)，对测站取反；乘1000使距离残差为mm。坐标改正数m、定向改正数rad。

## 随机模型与方差分量

sigma_L读取输入；sigma_S²=a²+(b*D_m/1000)²（mm²）。此式用于定权，不是全部平差模型。

P=diag(1/sigma_i²)，B=P^(1/2)A，c=P^(1/2)l。解 min||B delta_x-c||²；坐标解算使用SVD最小二乘。法方程形式为 A^T P A delta_x=A^T P l。

重新线性化至最大改正数小于1e-9（m/rad），40次上限；超限或额外秩亏报错。

Q=(A^T P A)^-1；r_i=1-p_i*a_i*Q*a_i^T。D_T=sum_T(pv²)/sum_T(r)，D_S同理。保持方向基准，每轮距离方差乘D_S/D_T，比例偏离1小于0.01停止，最多12轮。

左线约束网的比值为1.053、1.013、1.003，右线0.786、0.935、0.982、0.995，均吻合历史输出。这些数字是结果，不是写死参数。

## 基准与精度

固定网将已知点移出未知量，u=2*n_unknown+n_station，f=n_obs-u。自由网全部点未知，有两平移一旋转亏损；用三项内约束选定基准，求协方差时扣除人工约束方差，f=n_obs-u+3。

自由网公共点转换和历史坐标精度表达尚未复现，仅比较基准不变的观测改正数和调权序列。

sigma0²=v^T P v/f；C_x=sigma0² Q；MX=sqrt(C_XX)，MY=sqrt(C_YY)，MP=sqrt(C_XX+C_YY)，m转mm。

相邻点精度需要C_delta=C_ii+C_jj-C_ij-C_ji，不能简单相加两个MP。历史相邻边椭圆及主轴方向尚不在1775项验收内。

## 高差网

h_ij+v=Hj-Hi；A每行起点-1、终点+1，固定点项移右侧，P=1/L_km。白化最小二乘后求残差、协方差和高程中误差。

左线134观测、59待定高程、f=75、sigma0=1.5880357 mm/sqrt(km)；右线116观测、50待定、f=66、sigma0=1.6241736。高程与中误差吻合OUR的取位。

本例为IN1测站至目标高差网，不是IN3相邻点网。由共同观测推导多条高差可能相关，不能默认任意三角高程网都可用对角权阵。

## 比对准则

COR坐标4位小数(m)用0.00005m；精度2位小数(mm)用0.005mm；OUR高程5位小数用0.000005m；改正数2位小数用0.005秒/mm。这是打印取位半单位，不是工程限差。

独立函数仅读IN1/IN2，无COR/OUR也可求解；单独改变一条距离会改变成果，已纳入测试。

SUC诊断的常规两面归算与IN2最大差异约0.017秒、0.035mm；未改正高差与IN1最大差异约1.21mm。需核实球气差、常数、距离归算和截位顺序；诊断不发布正式IN1/IN2。
