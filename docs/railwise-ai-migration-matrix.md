## 实机复测发现并修复（2026-09-19）

- 控制网的默认导入/分析曾错误进入监测时序页；新增专业来源与精度子页，四阶段跳转保留所选测量网络。
- 未校核的可解析来源曾能直接点击平差；界面现在要求先完成质量校核。
- 一次性平差曾因没有观测期次被标成仅审计，无法进入成果链；观测期次要求现仅用于多期变形比较，仍保留当前来源准入和有效性门禁。
- 摘要点数改用网络中去重后的已知/未知点；质量 revision 更新会刷新摘要。
- GSI 的显式控制点映射原先只有 Runtime 入口；候选界面增加米制控制点输入，映射改变会生成不同的导入幂等键。
- 设置帮助与运行时显示文案改用统一品牌变量；仓库链接统一使用 railwise-cn/railwise-ai；旧来源格式和系统凭据提示保留技术旧名。

上述修复需要新候选包复验，不追溯修改旧候选包验收结论。

图标由固定版本 resvg 从无字体依赖的 SVG 直接生成；生成器不启动应用，不依赖隐藏窗口截图。新增构建依赖采用 MPL-2.0，属于开发工具，不进入 Runtime。
