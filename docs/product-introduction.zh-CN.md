# RAILWISE AI 与 RAILWISE Survey

RAILWISE AI 是本地优先的桌面工作平台。主入口分为“编程 / 内业”；RAILWISE Survey 面向工程测量内业，把原始测量资料处理为可复核、可追溯的计算结果和候选成果包。

本文同步产品收敛方向与当前实现边界。新的命名和四阶段界面仍在隔离候选包中验收；公开 0.5.0 安装包不因本文更新而自动变更。

## 工程测量内业

Survey 的核心流程为：

**原始文件 → 来源识别与预检 → 建网和基准确认 → 确定性平差 → 精度与异常复核 → 成果包 → 人工审查。**

任务可选择控制网、水准网、导线网、任意设站、变形监测或 GNSS，并记录坐标系统、高程基准、测量等级以及规范版本和条款。任务配置用于保存专业上下文；填写规范名称并不意味着已自动执行该规范的全部质量检验。

工作区按导入与预检、建网与平差、分析与精度、成果与审查四个阶段组织。工程 AI 对话持续保留，计算数据和结果由本地确定性 Runtime 生成。模型不可用时仍可手动进行导入、校核、平差与成果操作。

- **来源预检**：保留原始文件哈希、解析器身份、记录锚点和处置原因。识别出厂商或文件扩展名不代表该文件可以平差。
- **计算与复核**：支持已实现策略的水准、导线、平面控制、三角网、CPIII 设站、GNSS 基线及坐标转换。GNSS 接收机原始数据不能直接替代具有基准和协方差的基线成果。
- **控制点输入**：候选界面允许导入时显式提供已知控制点；单位为米，冲突坐标会被拒绝，不覆盖仪器原记录。
- **精度证据**：查看观测残差、闭合差、点位精度与原始记录锚点。没有项目限值或专业复核的结果不能自动宣称符合项目规范。
- **成果与审查**：生成 DOCX、PDF、XLSX 和关联清单，记录输入与输出哈希。候选成果与已审查成果分开显示，生成文件不等于完成专业签认。

当前真实样本验证覆盖 Leica GSI 水准与 COSA IN2 平面控制数据。包内 Runtime 已完成两组数据的完整成果校验；GUI 操作、界面适配、签名公证和升级链按候选提交另行记录，不能互相替代。

## AI 协作和模型

0.5.0 默认模型为官方模型 ID `deepseek-flash`（DeepSeek V4.1-Flash）。主 Agent、写作、定时任务等共用模型服务配置；旧 Flash ID 和 `deepseek-v4-pro` 保留兼容与显式选择能力。

Runtime 已接入思考模式、工具调用、上下文压缩、缓存统计以及结构化图片消息等适配。模型实际可用性、输入输出上限和收费以当前服务端及账户为准。未取得真实服务验收的能力不因设置中出现模型 ID 而视为完成验收。

普通咨询直接回答；修改项目或执行计算、导出等操作使用明确的参数和审批流程。AI 对数字的解释不替代确定性计算或人工专业判断。

[DeepSeek 官方更新](https://api-docs.deepseek.com/updates) · [Runtime 接入边界](./DEEPSEEK_HARNESS.zh-CN.md)

## 其他工作工具

编程入口支持项目文件、对话、工具执行、测试与变更审查。写作、设计、Flow、插件和定时任务属于侧边工具，不改变“编程 / 内业”的主入口语义。

写作支持 Markdown、附件资料和文档导出；设计和 Flow 提供各自工作区。专业内业成果与写作、设计、Flow 的深度协作仍属于后续范围，不能将通用工具入口等同于已完成专业联动。
