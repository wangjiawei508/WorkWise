# Survey 高级评差方法预审与先验残差诊断增量

日期：2026-09-19。这是用户授权的智能体模拟数值方法预审，不是测量规范符合性证明、真实工程专业签章或用户验收。本次新增独立诊断核、闭式参考测试及水准网只读 Runtime 诊断接口，不改写已有 `workwise-survey-adjustment-7` 结果，不接 UI、不改变公开版本。

## 先修正方法名称与统计量边界

`survey-service.ts` 的水准、部分平面/导线/坐标变换分支目前计算 `abs(v_i)/sigma_observation_i`，并以超过 3 标记待核查项。这是观测先验标准差归一化的残差幅度，不能直接称为 Baarda 数据探测或 Student-t 检验。观测有杠杆率时，残差的方差与观测方差不同。

GNSS 基线分支不同：已使用 `C_ll - A C_xx Aᵀ` 的对角并乘后验方差因子计算分量标准化残差。它不是“所有策略均除观测 sigma”的情形；但使用同批残差估计尺度后，也不能直接把该统计量当作已知先验尺度的标准正态量或外学生化 t。零残差方差分量目前显示 0，也不能被解释为“检验通过”。这些是后续 UI/结果语义迁移需处理的边界，本次保留历史结果不重写。

## 新诊断核的数学合同

实现：`kun/src/engineering/survey-statistical-diagnostics.ts` 的 `diagnoseAprioriResiduals`。

输入是同一线性/已线性化模型中的残差向量 `v`、**已含已知先验尺度的残差协方差** `C_vv` 和残差自由度 `ν`。不接受“后验估计”或“观测协方差”类型标记。调用者必须提供这些数据的模型来源，函数无法仅凭数值矩阵识别其物理来源，也无法识别已错误标成先验残差协方差的矩阵。

若原模型为 `l = A x + ε`，观测协方差 `C_ll` 已知且正定，`A` 列满秩，则：

```text
C_xx = (Aᵀ C_ll⁻¹ A)⁻¹
C_vv = C_ll - A C_xx Aᵀ
ν = n - rank(A)
z_i = v_i / sqrt((C_vv)_ii)
```

残差采用 `l - A xhat` 或相反符号均可，但签名统计量与传入残差保持同号。只有当随机模型、已知先验尺度、线性模型及高斯假设成立时，每个可检验分量的 `z_i` 才有标准正态边缘分布；分量之间通常相关。

本核返回有符号 `standardizedResidual` 和绝对值，明确 `statistic = signed-apriori-residual-z`、`decision = not-evaluated`。不返回 p 值、临界值、“粗差已确认”、t 分布判定或工程等级符合结论。对相关观测，它是**边缘残差标准化**；指定原始观测偏差的广义数据探测还需根据偏差模型与权矩阵构造得分，不能把它直接命名为完整 Baarda 算法。

数值校验包括：维度/有限值、正残差方差、非零整数自由度、矩阵对称性、半正定、协方差秩与自由度一致、残差属于协方差值域。协方差先按各轴标准差归一化，使用带主对角选主元的 Schur 消元检验半正定；允许残差协方差正常的秩亏，不要求它正定。归一化矩阵容差为 `1e-10`；非零标准化残差向量先除以 `max|z|`，再以 `1e-8` 校验消元余项，零向量单独保持零。接近秩判定边界的矩阵可能被拒绝，不能用调整阈值强行通过；应回查模型和数值条件。

任何一个分量残差方差为零都拒绝整次调用，由调用方明确显示不可检验；若拆分可检验分量，必须同时计算所选协方差子矩阵的正确秩，不得直接沿用原整网自由度。不会用 epsilon 作分母，也不会把无冗余变为零统计量。最多 256 个残差，当前是小型诊断核；大型网须另行设计稀疏/分块实现。

### 外部学生化/删除残差（已新增独立核）

`diagnoseDeletedResiduals` 仅接受独立观测的固定线性 WLS 合同：观测权 `p_i>0`、未乘后验方差的残差协因数 `Q_vv`、全模型加权残差平方和 `SSE=vᵀPv` 以及 `ν=n-p`。它要求 `ν>1`，并把 `R=P^{1/2}Q_{vv}P^{1/2}` 校验为残差投影矩阵（对称/幂等、`0<r_i≤1`、迹为 `ν`）。这会拒绝将后验缩放协因数、相关观测协方差或不相干的杠杆值冒充独立 WLS 的 `Q_vv`。

逐观测的删除方差与外部学生化量为：

```text
SSE_(i) = SSE - v_i² / Q_vv,ii
s²_(i)  = SSE_(i) / (ν - 1)
t_i     = v_i / [sqrt(s²_(i)) sqrt(Q_vv,ii)]
df(t_i) = ν - 1
```

实现对 `SSE_i≤0`、零或未解析的删除方差、非法杠杆、相关/非线性模型、错误 SSE、零/负权和 `ν≤1` fail-closed；不套用 3σ，不生成临界值或 p 值，不自动剔除观测。测试新增 6 项，使用独立的六点直线 WLS leave-one-out 重新拟合核逐点核对分母与 `ν−1`；另有均值完美删除、权整体缩放、错误 SSE/后验协因数、非法杠杆等负向覆盖。该文件当前共 14 项测试通过（原先先验 z 测试仍保持）。

### 第二轮独立数值复核

本轮确认并修复值域校验的幅度依赖缺陷：旧容差 `1e-8 × max(1, max|z|)` 会接受 `C=[[1,-1],[-1,1]]`、`v=(10^-12,10^-12)`，尽管该向量完全在 `C` 的零空间中。归一化向量后，幅度为 `10^-200`、`10^-12`、`1`、`10^200` 的同类非法输入全部拒绝；合法对比向量 `(s,-s)` 与零向量保持可用。另以 `C=[[1,1,0],[1,1,0],[0,0,1]]` 验证中途换主元后的秩与值域校验。消元中间量若超出数值范围也明确拒绝。

这两个新增测试在修复前均失败、修复后通过；该文件现在 **16 项测试通过**，Runtime `npm run typecheck` 和两个目标文件的 ESLint 通过。本轮未运行全量构建，也未改变生产平差结果。六次独立直线删点重拟合对照仍通过，确认外学生化的删除方差和自由度合同。

这些校验是同一数学模型的必要一致性检查，无法证明调用者给出的矩阵来自真实仪器随机模型。Student-t 分布解释还要求固定线性模型及独立高斯误差；线性化近似、残差相关性和实际权值可靠性仍须单独评估。本轮是智能体模拟数值预审，不能作为真实专业人员签认。

## Student-t 必须另建正确的删除残差分母

对于已正确白化且误差独立同方差的线性回归，令白化残差为 `e`，帽子矩阵对角为 `h_ii`，`SSE = eᵀe`，`ν = n-p`。删除第 i 个观测后的方差估计和外学生化量是：

```text
s²_(i) = [SSE - e_i²/(1-h_ii)] / (ν-1)
t_i = e_i / [s_(i) sqrt(1-h_ii)]
df = ν-1
```

要求 `ν>1`、`1-h_ii>0`、删除后保持参数秩、`s²_(i)>0`，以及拟合与随机模型一致。不能把 `e_i/sqrt(SSE/ν)` 或本核 z 直接代入 t 临界值。白化若混合了原始相关观测，删除一个白化分量也不等于删除一个原始仪器读数；这种场景须明确偏差/删除单位或重新拟合完整相关模型。

NIST [Student-t 临界值表](https://www.itl.nist.gov/div898/handbook/eda/section3/eda3672.htm) 已由主任务于本日 HTTP 读取，本子任务核对其保存 HTML：双侧 α=0.05 使用 0.975 列；df=1、2、10 对应约 12.706、4.303、2.228。它们仅可用于正确构造并满足假设的 t 统计量，**不是测量等级限差，也不是 z 的阈值**。

NIST [异常值检测说明](https://www.itl.nist.gov/div898/handbook/eda/section3/eda35h.htm) 区分标记候选、稳健处理和正式识别，并说明分布假设及多异常值问题。后续实现必须记录单/双侧、α、检验家族及多重比较规则，不可把逐点超阈值一律转为自动删除原始观测。

本次核对网页快照 SHA-256：t 表 `8b1dd124f3f61210714b47ef00cea44ce5a17ad80912a6495057660e3e580242`；异常值说明 `35189e81465d2b7d77f43a5bba99c57b426759f94f913fff8bcdc9baacf194aa`。这些来源支持统计方法背景，不替代中国工程测量或质量检验标准原文。

## 水准网只读 Runtime 接入

新增合同 `kun/src/contracts/survey-statistics.ts` 与 `SurveyService.getAdjustmentStatisticalDiagnostics(projectId, adjustmentId)`。认证接口为：

```text
GET /v1/engineering/projects/:projectId/adjustments/:id/statistical-diagnostics
GET /v1/engineering/projects/:projectId/adjustments/:id/statistical-diagnostics?download=1
```

第二种形式下载同一 JSON 诊断记录，响应禁止缓存。它是带 `diagnosticsVersion=leveling-deleted-t-1` 的独立补充记录，绑定项目、网络、run/result、inputHash、原平差算法版本、源文件 SHA-256 和原结果 calculationHash。每个观测保留 `observationId`、`sourceRow` 与 `sourceRecordId`。既有结果对象、平差算法版本、校核分类、结果哈希和历史文件均不改写。

计算先经过项目范围严格结果复验，只有当前来源、冻结输入、不可变结果证据及确定性重算一致，且原平差为 completed/valid，才进入诊断。跨项目查询返回 404；缺失或篡改原始文件、过期网络或不一致结果拒绝新计算并返回 409。历史读取接口保持可用。错误响应采用固定文本，不回显可能包含测点或测量值的内部来源错误。

当前仅支持 `leveling` 和 `height-control`。生产水准求解和诊断复用同一方程构造函数，由相同 `A`、`P` 与参数协因数构造 `Q_vv=P^-1-A Q_xx Aᵀ`，再调用已验证的外学生化核。全部观测采用声明 sigma 或全部采用路线长度权才可计算；混用两种权基准、声明观测协方差、自由度不足、零/数值未解析的删除方差、不可检验残差或超过 256 个观测时返回明确的 `unavailable` 原因。GNSS 及其他网型不会套用该公式。

可用记录明确列出删除后验方差、输入权基准、残差单位 m、无量纲 t、全模型及删除后的自由度，以及固定线性模型、独立高斯误差、相对权可靠性和固定已知基准假设。`assumptionsVerified=false` 与 `decision=not-evaluated` 恒成立：数值可算不代表现场随机模型获证实，也没有 Baarda、临界值、多重比较或自动剔除结论。当前不为被旧质量规则判为 invalid 的结果绕过严格新用途验证。

新增 Runtime/HTTP 测试使用实际导入、持久化平差及严格复验路径，以逐点独立删除后重新估计的加权均值和预测误差校核 t 与删除 SSE；覆盖路线权、零方差、低自由度、混合权、相关声明、超规模、GNSS 拒绝、跨项目、过期输入、原始文件篡改/缺失、鉴权、JSON 下载、错误内容脱敏和历史结果不变。连同原统计核、生产水准/其他策略与原路由回归，本轮 **6 个文件 88 项测试通过**；Runtime 类型检查及目标 ESLint 通过。未运行全量构建或完成候选包 UI 验收。
