# 高级试算精确包验收材料

这里是验收输入与独立核算工具，**不是已经完成的安装包验收报告**。实际包的版本、提交、ASAR、签名公证、真实 updater、GUI 和重启结果应另存到对应源码提交的 evidence 目录。

三个 JSON 都只用于试算验收，不能当现场数据或已确认生产协方差：

- `inputs/w-diagonal.json`：显式完整绝对 C 为 diag(1,2,3) m²。独立分数计算得到均值 18/11 m，残差 [-7/11,4/11,15/11] m，先验加权平方和 12/11，残差协方差 diag(1,2,3) − (6/11)11ᵀ。首观测方向 w = −7/√55，共模方向不可检测。无显著性/删观测判定。
- `inputs/vce-single-group.json`：四个等精度合成值 [1,2,4,5] mm，均值 3，残差 [-2,-1,1,2]，自由度 3。方差候选为 10/3 mm²，两轮收敛；不改正式权。
- `inputs/vce-nonpositive.json`：AMIRI2007 Example 4.8 的公开算例重建，来源见相邻 `railwise-vce-trial/README.md`。相同初始权下 N 的对角为 5/8、非对角 1/8，首轮方差候选 [-37/25,42/5] mm²；应保留负值并停止，不能截断为零或声称收敛。
