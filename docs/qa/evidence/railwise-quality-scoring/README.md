# GB/T 24356—2023 声明检查记录评分纯核

日期：2026-09-20。入口 `kun/src/engineering/survey-quality-scoring.ts` 的 `scoreSurveyQualityV1(raw)`。本次交付为独立纯计算模块；尚不代表产品界面、持久化、工程批准或公开发布已完成。

## 实现范围

- 绑定源文 SHA256、算法版本、产品版本和检查阶段。仅支持平面控制（点，表43/44）与高程控制（测段，表45/46）。两类相同数字权重不意味着缺陷项目相同；分类计数由调用方声明，未自动查验。
- 单项/多项数学精度、声明 A/B/C/D 扣分、显式七子元素分层评分、概查、样本、最终检查批、验收批分别处理。每次请求保存解析后声明、SHA256、原权/有效权、条文路径和范围完整性。
- 阈值与评分采用约分 BigInt 有理数，不先舍入，不用 epsilon。输入只接受有界十进制或分数字符串；输出是精确分子/分母字符串。
- 缺失、明确排除、已检查分开；部分范围逐层归一，不以缺失充当排除。A 或低于60的子项不可被平均抵销；失败输出不伪造综合得分。B=9 时保留原始 -8，不截零。
- 样本成员显式声明，缺成员不可通过；合格成员必须声明完整产品范围。最终检查批使用实际批 N 与独立既有合格前提，整数交叉相乘检查90%/50%与80%/30%阈值。验收仅判声明合格/不合格，不套优良等级。

## 明确不覆盖

`status=declared-inspection-trial-only`；引用、人工分类、既有批资格均未验真。没有自动工程批准、签字、删点、正式成果修改，也不更新旧质量计划。

本核不从平差残差推导 m，不推断抽样合规，不执行全表缺陷自动分类。m>m0、多精度组出现恰好60、调整 t≠1 返回明确不可用原因；已声明 A 可独立否决。t<=0 等非法输入优先拒绝。单项60有效。第一版要求同精度组使用同一单位标识是软件限制，不能解释为标准禁止各项用各自单位标准化。

公开 profile 固定权树；内部 rules 的任意权参数仅为数值测试基元，不能代替公开 source/profile 绑定入口。所有输入资料仍需实际检查并按适用工作流程签认。

## 有界资源

64项精度、128个样本成员、每处32条唯一证据引用、计数上限1,000,000。数字整数/分母最多24位、十进制小数最多24位；表达式不接受科学计数或隐式浮点。运算分子/分母限制16,384 bits；预算用尽返回 unavailable。预检限制深度12、节点32,768、单数组128、文本总量1,048,576个JavaScript UTF-16码元（字符预算，非UTF-8字节预算），防止超大/循环声明直接进入解析。
