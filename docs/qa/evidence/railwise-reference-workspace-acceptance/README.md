# 两历元参考工作区验收准备

此目录是后续精确包的验收输入，不是已完成的包内 GUI 证据。a606a86 包只有参考纯核，未包含工作区接入。

三例均为一维合成模型，调用方来源摘要是明确占位，不认证真实资料或专业稳定点。两期坐标分别为 [0,10,20]、[2,14,27] mm，指定参考 a、b。

- `reference-gls`：两期各为单位协方差，GLS 权 [.5,.5,0]，平移 3 mm/方差 1 mm²，位移 [-1,1,4] mm，完整位移协方差 [[1,-1,0],[-1,1,0],[0,0,3]] mm²；平移与位移协方差 [0,0,-1] mm²。
- `reference-singular-gls`：两期各 C=[[1,-1,0],[-1,1,0],[0,0,1]]，必须保留 GLS 秩/病态不可用，不自动换方法。
- `reference-equal`：同一奇异模型，明确改为等权参考；平移 3 mm/方差 0，位移 [-1,1,4]，位移协方差 [[2,-2,0],[-2,2,0],[0,0,2]] mm²；保留“半正定或数值容差内未分辨”，不宣称稳定或精度最优。

每例应在独立合成项目中通过 GUI 创建，核对所有参考权、完整矩阵、单位与解释。检查原文字节/依据、严格重放、历史、重新核验、原生导出取消/成功、重启同 ID、篡改拒绝/恢复，以及中文浅色和英文深色支持窗口尺寸。人工 UI 和专业签认仍单独记录。
