## 结论

未发现本次样本的 GSI 解码、累计量差分或平差内核计算错误。最大距离差 `0.48629 m` 能由参考 IN1 的打印量化充分解释；7 条高差差异仍缺少原转换过程的证据，不能整体归结为四舍五入，也不能以数值比较通过替代来源闭合。

## 方法与归因

独立读取 GSI8 的 WI41 分块，以单位码 8 的十进制原始数值计算相邻 WI83 高程差、WI574 累计距离差；再按参考端点压缩中间转点，核对 14 条路线的端点顺序。另用原始 BFFB 的 331/332/336/335 读数计算每站两次高差的均值，再累加为路线高差。后者只是原始读数复算，不自行添加尺长、温度、视准轴或其他仪器改正。

数值计算复用现有独立检查器的 `numpy.linalg.lstsq`、距离反比权和残差方差方法，不调用产品平差内核。分别替换参考高差与参考距离，得到相对候选的最大高程差：

| 独立计算输入 | 最大高程差（mm） |
| --- | ---: |
| 同源 GSI 压缩后的 14 条路线 | `1.0658141036401503e-11` |
| 仅替换为 IN1 高差 | `0.02017777466178927` |
| 仅替换为 IN1 距离 | `0.0007124150336323964` |
| 同时使用 IN1 高差和距离 | `0.02031550931747006` |

这说明原报告的约 `0.0203155 mm` 高程差由输入差异驱动，主要来自参考高差。各列是不同点集上的最大值，不能直接相加。十进制重建输入与直接复用候选浮点输入会产生极小数值差异，不改变上述归因。

本地探索中的常见统一舍入方式也未能完全复现所有参考高差。现有文件不能唯一确定原转换器的版本、中间舍入顺序、仪器改正或人工编辑记录，因此这 7 条高差保持 `unresolved`。同源计算一致不证明参考转换过程正确，更不证明现场观测满足工程要求。
