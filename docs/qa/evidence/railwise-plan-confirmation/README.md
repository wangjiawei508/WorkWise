- Typed Plan 显示固定参数、前序输出绑定、预期产物和可逆性。缺输入、多候选输入、历史缺审查信息时不可执行。

- 新平差读取绑定其运行 ID。重建计划保留原操作及选择，重新获取修订并要求重新审批。
