## 方法输入与验收边界

### 自由网与拟稳

LOESLER-2017 纸页 43/PDF 3 的式 (3) 使用带基准约束的增广系统，残差自由度为 `r = n - u + g`，其中 `g` 是基准亏损。自由网不能任意固定一个点后继续称为无外部约束自由网，也不能给法方程添加小对角数以隐藏秩亏。

GAMA-2.29 §2.7 明确：正则化点选择定义最小改正的基准；这是数学基准选择，不是该点物理稳定的证明。LOESLER-2017 纸页 50/PDF 10 对其水准参考网说明：只有两个参考点时，无法唯一归因某个参考点移动；为了区分不稳定参考点，应有至少三个参考点。该例的建议不能泛化成所有网型的充分条件。

后续拟稳输入至少包括两个历元的点对应关系、各期完整随机模型、跨期相关性是否存在、候选参考点、独立于计算的稳定性依据、统计假设、多重检验规则和迭代停止规则。必须测试整体基准平移、单点移动、共同移动、参考点不足和多个同等解释。不能把“未拒绝零位移假设”写成“证实绝对不动”。

论文 PDF 11 的表 7/8 提供 Delft 网点位移和块平移比较数值，但本轮没有获得 Kok (1983) 的完整原始观测、权模型与各期配置；这些表值目前只能当文献比较结果，不能登记为本产品已重放通过的金标准。Onsala 表 5/6 同理。

### 方差分量估计（VCE）

AMIRI-2007 式 (4.6)：`C = Q0 + sum(theta[k] * Q[k])`。必须固定功能模型、已知协因数基、分组、初值、估计器、权矩阵和是否采用非负约束；有效总协方差须满足求解所需的正定条件。

纸页 62/PDF 74 指出：`Q[k]` 线性独立只是必要条件；真正需要在残差/条件空间中检查 `B^T Q[k] B` 的线性独立性。多个仪器组、正观测数或更多重复观测不自动保证可辨识。

可执行文献基准为例 4.8，纸页 61/PDF 73：

```text
A = [1, 1, 1, 1]^T
y (m) = [10.0016, 10.0009, 9.9991, 10.0036]
Q1 = diag(1,1,0,0), Q2 = diag(0,0,1,1)
初始分量 (1,1)，W=I：第一次无约束估计 = (-1.48, 8.40) mm^2
初始分量 (1,10)：第一次约为 (0.198, 5.463) mm^2
论文报告迭代收敛约为 (0.235, 5.184) mm^2
```

第一行输出已另外用论文式 (4.126) 和 Python `Fraction` 精确算术核算，得到 `(-37/25, 42/5) mm^2`。后两行是论文报告值，本轮没有重新实现其迭代。不能用四舍五入表值要求超出其有效位数的吻合，也不能截负值到零后伪称复现了无约束估计器。

拒绝基准：例 4.9 的 `A=ones(m,1)`、`Q1=I`、`Q2=ones(m,m)` 中第二分量不可辨识。还须验证近病态模型、无组内冗余、错误分组、负估计和最大迭代耗尽。蒙特卡洛应检验偏差/覆盖率及其抽样置信区间，不能要求单次随机样本的估计恰好等于真值。

### Baarda / 广义数据探测

AMIRI-2007 纸页 17/PDF 29 式 (2.39)，采用 `v=y-A*xhat`：

```text
w(c) = (c^T C^-1 v) / sqrt(c^T C^-1 Cvv C^-1 c)
H0: E[y]=A*x；H1: E[y]=A*x+c*b
```

`C` 必须是已知先验观测协方差；`c` 是明确的偏差方向。若 `c` 落在 `A` 的列空间，分母为零，该偏差不可探测。只有独立观测且 `c=e_i` 时才能简化成逐项 `v_i/sqrt(Cvv_ii)`。未知尺度、相关观测和多维偏差不得套用同一个简单公式。

相关观测反例（本轮另以 NumPy 2.3.5 线性代数核算）：

```text
A=[1,1,1]^T, y=[0,11,2], C=[[4,1,0],[1,9,0],[0,0,1]]
xhat=103/46
v=[-103,403,-11]/46
diag(Cvv)=[149,379,11]/46
边缘 z 约为 [-1.24412832, 3.05215458, -0.48900965]
c=e_i 的广义 w=[-19/sqrt(115), 49/sqrt(230), -sqrt(11/46)]
                  约为 [-1.77175914, 3.23096432, -0.48900965]
```

完整功能还需总体检验、预先声明的显著性/功效、检验家族和多重性、最小可探测偏差以及掩蔽/淹没评测。现有先验 z 与外部学生化 t 增量不是完整 Baarda；检验标记也不授权自动删除原始观测。

### 抗差估计

HUBER-1964 的位置模型损失为 `rho(t)=t^2/2`（`|t|<k`），否则为 `k*|t|-k^2/2`。实施前必须声明标准化残差使用的尺度、`k`、尺度是固定还是联估、初值、停止条件以及最终协方差的含义。重定权后的逆法矩阵不能不加说明地作为原高斯 WLS 的精度证明。

最小闭式基准：位置数据 `[0,0,0,10]`，固定尺度 1、`k=1`，Huber 最小值位置为 `1/3`，普通最小二乘为 `2.5`。另对 `[0,0,10,10]`，同一尺度与 `k` 下 `[1,9]` 全段都是最小点，应报告非唯一/不可据此声称唯一稳健解。清洁数据、极端值、多异常、单位尺度变化、坏初值、秩损失、不收敛和每步权重审计均须覆盖。高杠杆污染不能仅由 Huber 截断残差的例子宣称解决。

## 建议下一增量：一维自由水准网只读试算核

范围仅为连通、独立观测、正权的线性高差网，基准亏损恰好为 1。输出独立版本的补充记录，暂不替换已有 `workwise-survey-adjustment-7` 结果，也不绕过导入准入、人工审批或历史证据校验。

明确合同：输入点 ID、边 ID、原始记录锚点、高差与单位、权及其来源、参考高程 `H0`、显式数学约束 `sum(H-H0)=0`。初版全部点参与内约束，暂不实现自动拟稳点选择。输出 `H`、高差可估计量、残差、`Q_HH`、基准亏损、秩、自由度和基准约束；只有明确先验尺度时报告先验协方差。后验尺度及自由度另列，不能混称。所有结果保留模型假设未验证、工程判断未执行的状态。

### 解析金标准

采用 `l=A*H+epsilon`，`v=l-A*Hhat`，长度单位 m，`P=I`（协因数模型）：

