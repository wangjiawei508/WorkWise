# 自由水准网服务与界面验收

本目录的三点闭环完全为合成数据，用于显式零和内约束的独立验算，不是实际工程或生产指标样本。已发布的 0.5.0 和历史候选包不能证明本轮新界面通过。

## 独立预期

三个点的 H0 均为 0 m，三个高差依次为 1、2、−2.7 m，等权。闭环不符值为 0.3 m，各观测 `observed − adjusted` 残差为 0.1 m。自由网约束 `H_A + H_B + H_C = 0`，所以点高程依次为 −37/30、−1/3、47/30 m；调整后高差为 0.9、1.9、−2.8 m。秩 2、基准缺陷 1、自由度 1、加权残差平方和和后验方差因子估值均为 0.03。

这些是任意零和基准下的试算高程。A 原先是固定点，试算释放 A 的约束，但原始网络、正式平差和成果审查状态均不得变更。自由网不能据此得到绝对高程精度或工程合格结论。

## 验收范围

- 服务：显式确认、完整观测转换、单位与权、原角色保存、幂等创建、项目隔离、持久历史、严格重放、源数据篡改拒绝和失败不留半条记录。
- 桌面：只有确认约束和权策略后才能计算，历史读取不等于新计算；中英文、原始锚点定位、失败重试、切网及离线迟到响应。
- 安装包：须对最终源码的独立签名包另行记录实际操作、截图、重启恢复；自动化和旧包证据不能代替这一步。

本轮新增的复验审计事件为独立证据，保留原成果及审查状态。聚合器只读数据库快照，记录时点的通过率与当前重新读取文件的验证必须区分；候选数据与正式生产数据分别统计。
