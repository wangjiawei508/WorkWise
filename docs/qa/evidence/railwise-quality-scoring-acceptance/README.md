# 声明检查评分的精确包验收准备

这是后续工作区/签名包的验收输入，尚未执行包内 GUI。全部为合成检查计数，来源引用不代表真实检查记录或人员签认。

- `quality-full`：平面控制点的七叶分数依次 80、83、90、100、99、98、97；固定权树下精确总分 9141/100（91.41），声明等级“优”。数学精度 m=13/20、m0=1，依据式(3)得80。必须保留“声明检查记录”、来源未验真和非工程批准。
- `quality-child-veto`：观测质量改 B=4，子分52；任何高平均分不得掩盖该项，结果不合格、正式综合分为空，逐叶记录保留52。
- `quality-pending`：资料完整性仍待查，不能改当“明确排除”，结果不可评定而不是通过。
- `quality-multiple-sixty`：多项数学精度一项60、一项100；因所有单项严格大于60的聚合前提不满足，明确不可评定，不擅算80。

GUI 须核对精确分子/分母、各层原权/有效权、范围与条文路径；执行声明/确认门禁、原字节保存、重验导出、原生保存取消和成功、完整重启同ID、篡改拒绝/恢复及双语主题与支持尺寸。实际数据库独立核算待接入格式冻结后执行，不以纯核或 DOM 检查冒充打包验收。
