## Audit Helper Correction

The first before run failed at `audit.py:353`, calling the original
`legacy-monitoring-helpers.py:167`. Python treats `bool` as an `int`; the numeric
comparison therefore attempted `float('false')` for an exported workbook flag.
The actual exception was `ValueError: could not convert string to float: 'false'`.
This was a helper type error, not evidence that the product arithmetic failed.
The original failed public summary is preserved, including its unchanged-files
result. No product data or product code was changed to obtain a pass.

The corrected comparator handles boolean values before numbers. It accepts the
exact boolean or the workbook text `true`/`false`, rejects swapped flags and
numeric coercions such as `0`/`1`, and rejects booleans in numeric fields. Both
original helper/selftest files and unified diffs are included. The original
seven-test log and corrected nine-test log are retained separately. Corrected
before and after-restart audits both passed without additional helper changes.

## Files and Reproduction

The four phase directories contain public summaries only. The Python scripts,
PDF text helper, correction diffs and selftest logs are included for review.
The only archive-specific script edit is replacing the local username path in
`pdf-text.mjs` with the equivalent `pdfjs-dist/legacy/build/pdf.mjs` package
import. Other scripts and logs are copies of the executed files.

Scripts are evidence of this run, not a command to execute in the repository.
For a separately authorized rerun, use a new private audit directory outside the
repository, the original isolated fixture root, and Python 3 plus Node.js with
the repository's installed `pdfjs-dist`. Keep the source and package guards;
do not redirect them to real user data. `audit.py` rejects an existing output
directory. Its after-restart invocation must use the corrected before summary.
`selftest.py` uses exclusive creation for its log, so preserve prior logs before
running it in a fresh private directory. New SQLite copies and private integrity
reports generated by these tools must stay outside the public archive.

No SQLite database, copied database sidecar, private integrity/error file,
environment file, credential, or full database dump is included here. Record
identifiers and relative output paths in the summaries refer only to synthetic
fixtures. `archive-manifest.json` records hashes of the archived files.

## Scope

This is selected synthetic packaged monitoring-replay acceptance. Checks cover
complete source normalization and independent arithmetic, hash bindings and
replay chains, workbook values, document metadata, and SVG geometry. GUI visual
inspection is separate; these scripts do not assert pixel rendering. This audit
does not establish authentic field observations, standards compliance,
professional approval, production KPI performance, every application workflow,
or public release approval. All three selected manifests remain `draft`.
