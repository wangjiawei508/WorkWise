# 多组 VCE 独立数值复审

日期：2026-09-20。智能体独立数学与数值审查，**不是真人专业签认**。只读取 `/private/tmp/railwise-vce-trial` 隔离实现及原始方法资料；未更改主工作区、生产观测或正式权。

## 结论与实际核读

审查对象为 `disjoint-linear-vce-trial-1` 的合同、纯核、测试与文档。当前未发现剩余阻断缺陷。受限模型仍只有固定满列秩 A、独立互斥对角组、Q0=0；负分量不夹紧，迭代收敛不代表假设已核实、工程批准或普适最优估计。

本复审实际查看了 Amiri-Simkooei 2007 PDF 的第 66、67、68、73 页渲染图，对应印刷页 54、55、56、61。原 PDF 的 SHA-256 已独立复算为 `4c4b6311f6da13844f559c48a57a62cd5467434b51d563805ae176a7a4ec9207`。式 (4.110)/(4.112) 的 1/2、Q0=0、固定 Qg 更新方差分量的迭代约定与实现相符。原文第 68 页末明确不保证迭代收敛时严格最小方差；当前不输出分量协方差、不宣称普适最优是适当边界。

独立数值期望值生成器不导入产品算法、共享矩阵核或产品测试常量。

## 发现的缺陷及复测

与另一名审查智能体确认：原算法直接计算 `R=W-WA(AᵀWA)^-1AᵀW` 时，消减误差可能被大 q 放大，把投影后严格为零的协方差分量误判为可辨识。

本复审独立补充了残差自由度大于 1 的反例，证明不能只检查组数是否超过残差协方差空间维数：

```text
A = [[1,1],[.01,0],[.01,0],[.01,0]]
y = [0,1,3,5]
groups = [0,1,1,1]
q = [1e6,1e-6,1e-6,1e-6]
theta = [1e-6,1e6]       # C=I，n-p=2
```

第一条观测可由第二个参数单独完全拟合，第 0 组协因数对应的残差空间投影严格为零，所以这两个分量不可能都被辨识。原实现却返回 `N00≈1.03397576569e-13,N11≈1e-12`、条件数约 9.67 和候选 `[0,4e6]`，误将结构不可辨识解释成数值负/零方差边界。

实现者改为 Householder QR 残差空间 Gram，并增加无量纲组 mask Gram 条件门槛。该 mask 门槛有正确数学依据：在当前对角互斥模型中，白化后 `q_i*w_i=s/theta_g` 在每组内为常数，因此 mask Gram 和实际随机法矩阵是正对角合同变换，辨识性等价。额外条件数限制属于保守数值政策，不能改称工程判断。

修复后实测：

- `projected-zero-group.ts`：16 个 df=1、2、3、4 的专属参数/零投影组变体全部在产生候选前返回不可辨识。
- `unidentifiable-probe.ts`：4002 个 n=2、p=1、两个独立组、初始方差比 1e6 至 1e8 的变体均不可辨识，无虚假候选。
- `false-convergence-probe.ts`：288 个零投影组变体改变首条观测及公共基准，全部不可辨识，无正候选或假收敛。

原反例完整输出保存在 `projected-zero-group-before-fix.json`；修复后输出单独保存，没有覆盖旧证据。

## 独立多组首步与迭代对照

`exact_group_oracle.py` 用 Fraction 高斯消元求 `AᵀB=0` 的精确条件空间基。构造 `t=Bᵀy`、`Tg=BᵀQgB`、`V=sum(theta_g*Tg)`，独立求：

```text
Ngh = trace(V^-1 Tg V^-1 Th)/2
lg  = tᵀ V^-1 Tg V^-1 t /2
candidate = solve(N,l)
```

这没有复用生产实现的观测空间 QR/拟合/投影运算。固定 seed=20260920 生成 160 个小整数、2/3 组、非单位 q 的首步模型，显式比对候选及产品归一化的 N/l：

- 58 个负/零候选停止，83 个正候选达到人为指定的单步上限，19 个精确不可辨识。
- 0 个数值或状态不符，最大混合绝对/相对误差 `1.018935972940625e-13`；比较阈值 `1e-9`。
- 论文负例另以精确分数求得 `[-37/25,42/5] mm²`，没有用三位小数论文表格充当高精度真值。

`decimal_iteration.py` 在相同条件空间用 80 位 Decimal 独立迭代，包含 30 个生成模型及论文初值 (1,1)、(1,10) 两例，共 32 例：

- 24 例收敛；7 例非正分量停止；1 例数值范围停止。没有发现假收敛。
- 24 个收敛例的全部候选、最终分量、参数和残差最大混合误差 `6.2729187184526994e-15`。
- `random-44` 是明确的范围停止，不作为收敛成功：软件第 3 步后停止，高精度参考第 5 步才到分量范围边界；软件此前保存的候选最大误差 `1.2118549016189157e-9`（本复核容差 `1e-8`）。这说明保守数值停止会早于高精度求解，不能暗中改称数学不可解。

这些固定独立算例不是随机误差分布、估计偏差或工程覆盖率试验，也不证明所有输入均满足误差界。

## 合同与保留边界

追加的结果合同检查覆盖输出维度、迭代连续性、非正候选不能继续、converged 对应最终正候选及 finalFit、保存的停止策略和变化量一致性。schema 仍不是输入真实性或算法重放证明；未来接持久化/API 时需要保存完整 A/y/q/分组/初值/停止策略和来源绑定并重放，不能只保存输出摘要后声称可复算。

初始方差、q、观测值、条件数与迭代范围是软件限制；当前不能处理相关组、重叠组、Q0≠0、约束/自由网、非线性模型或生产权替换。收敛只证明该记录的数值停止条件被满足，不证明物理方差是真实值。
