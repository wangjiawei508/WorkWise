## 独立单组精确参考

`generate.py` 用 Python Fraction 对实际二进制浮点输入作精确有理数解：`x=(sum(a*y/q))/(sum(a*a/q))`，`theta=sum((y-a*x)^2/q)/(n-1)`。没有导入产品实现或共享矩阵库。生成 1356 个案例：756 个结构化尺度/基准组合，600 个随机非恒定单参数设计与不等 q。结构组合覆盖观测尺度 `1e-200..1e4`、基准 `0/1/1e4/9e5`、q `1e-8/1/1e8`、设计列尺度 `1e-300/1/1e300`，随机初始方差覆盖 `1e-18..1e18`。

初轮：757 converged，428 numerical-boundary，171 nonpositive；全部收敛方差与 Fraction 参考相对误差最大 `1.1042090367063269e-15`，没有错误或异常抛出。这里的比较用于数值实现，不证明工程模型假设。

## 发现 1：极小能量被错报为零分量

`A=ones(2,1),y=[-5e-201,5e-201],q=[1,1],initial=1`，精确方差是 `5e-401>0`，但双精度平方下溢为 0，最初返回 nonpositive-component 并记录零候选。已通知实现者增加非零残差加权值/平方/贡献的下溢及 subnormal 检查。修复后复跑 1356 例：756 converged，474 numerical-boundary，126 nonpositive，所有收敛方差仍与参考一致，最大相对误差不变；真零残差维持非正分量边界。前后减少的一项收敛是额外保守精度拒绝，没有伪造数值结果。

## 发现 2：投影消减噪声被 q 放大为伪可辨识

`A=[[1,1],[.02,0],[.02,0]],y=[0,1,3],g=[0,1,1],q=[1e6,1e-6,1e-6],theta=[1e-6,1e6]`。C=I，第一组唯一观测由第二参数完全拟合，该组投影严格为零，应不可估。旧实现 `W-WA(AᵀWA)^-1AᵀW` 的相消噪声经 q 放大后，输出 `N00=2.584939414228e-14,N11=5e-13,cond=19.34`，误报非正候选 `[0,2e6]`。这不是合法的零分量估计。

r=2 同样复现：`A=[[1,1],[.01,0],[.01,0],[.01,0]],y=[0,1,3,7]`，同组与 q 构造，`N00=1.03397576569e-13,N11=1e-12,cond=9.67`，错误候选 `[0,9.333333e6]`。仅加 `k<=r(r+1)/2` 不足以修复。

修复前探测：r=1 的 195 个模型中 16 个误分类；r=2 的 455 个模型中 19 个误分类。另固定种子 20260922 构造 10000 个第一组严格不可估的随机模型：7852 stochastic-rank，1237 nonpositive，911 numerical-boundary，0 个伪收敛。问题是不可辨识分类和中间候选证据失真，未观察到工程成果或正式权修改。

已通知实现者采用加权 Householder QR 残差空间构造投影，并独立检查无量纲分组 Gram 的可辨识性。修复复验已完成，详见下节。

## 最终复验与结论

被审源码 SHA-256：`593f4c3e5063e71b9d758299bdc3360454292b48fac520e2fc0d8aa472f7f9fa`。实现者以加权 Householder QR 残差空间构造投影，并检查无量纲 mask Gram。此受限模型中 `q_i*w_i=s/theta_g`，原随机法矩阵与该 Gram 仅相差正对角缩放，秩等价；该检查没有把任意未知相关协方差模型混入本合同。

全部 10650 个精确不可辨识模型现在返回 `stochastic-rank-or-conditioning`，无迭代候选、最终拟合或收敛方差。1356 个单组案例中 763 收敛、467 数值边界、126 真零/非正分量边界，没有异常或数值不符。收敛方差相对误差最大 `1.1731683692532264e-15`，残差以精确残差最大模归一误差最大 `5.183031964016193e-16`，拟合值以观测最大模归一误差最大 `2.731215320639424e-15`。比较阈值为 `1e-7`，没有以 `max(1, tinyExpectedVariance)` 吞掉极小方差相对误差。

本数值审查未发现剩余阻断问题，但只覆盖所列受限模型和算例，并非证明所有浮点输入、统计假设、仪器来源或真实工程适用性。输出不提供分量协方差（固定 null），因此没有冒称对其 PSD 或置信区间进行验证；检查的随机法矩阵与失败结果属于软件诊断。负分量、迭代上限和最终拟合一致性另由产品回归及独立多组审查负责。
