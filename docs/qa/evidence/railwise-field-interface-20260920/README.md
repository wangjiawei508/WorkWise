## 已核实的接口事实

| 主题 | 页码 | 事实及实现约束 |
| --- | --- | --- |
| 串行事务 | 5-6 | 点对点同步请求/响应；收到当前事务结果再发送下一条。设备缓冲溢出可能丢请求，适配器必须单事务在途且队列有界。 |
| 请求帧 | 6 | 请求以 `%R1Q` 开始，含 RPC、可选事务号、参数和终止符；可选前导 LF 会清空接收缓冲，不能不加区分地作为无副作用前缀发送。 |
| 响应帧 | 7 | `%R1P` 后分别有通信返回码和 RPC 返回码。必须同时解释，不能只看通信码为零。事务号须关联原请求。 |
| 事务号 | 6-7 | 可选事务号通常在 1-7 递增，响应复用它；省略时响应为 0。只有短事务号不能证明重连后旧回包的新鲜性，还需本地会话及接收序号。 |
| 单位 | 15 | 默认 SI：长度/坐标为 m、角为 rad、时间为 s、压力为 hPa、温度为 Celsius；各 RPC 显式单位优先于默认值。 |
| 时间例外 | 126、130 | `SYSTIME` 是开机以来的 ms，不能当成 UTC；`TMC_GetSimpleMea.WaitTime` 是 ms。接收 UTC、仪器原值和本机单调时间应分别保存。 |
| 硬件 | 180 | 此型号使用 RS-232；默认 19200 baud、8 data bits、1 stop bit、无校验、CR/LF。8N1 固定，波特率与终止符可变；连接时读取/确认实际配置，不能据默认值盲连。 |
| 通信异常 | 15-17 | 3077 为超时、3079 为版本不匹配、3081 为过程不可用、3093 为事务号不匹配、3100 为接收溢出。超时不证明仪器未执行命令；不自动重发状态未知的控制命令。 |

手册第 7 页日期例子的请求前缀与第 6 页通用请求语法不一致。实现以经逐项核实的通用语法和具体 RPC 声明为依据，不照抄这个例子作为金标准。

## 命令分级草案

| 命令 | RPC | 页码 | 本阶段处理 |
| --- | ---: | --- | --- |
| CSV_GetInstrumentNo | 5003 | 102 | 后续身份只读白名单候选，返回工厂序列号；日志应脱敏。 |
| CSV_GetInstrumentName | 5004 | 103 | 后续型号只读白名单候选。 |
| CSV_GetDeviceConfig | 5035 | 104 | 后续能力只读白名单候选，不能用名称推断精度等级。 |
| CSV_GetSWVersion | 5034 | 108 | 后续固件版本只读白名单候选；本页 C/VB 声明含 `GetSWVersion2`，以 ASCII RPC/版本合同为准。 |
| TMC_GetSimpleMea | 2108 | 124、130-131 | 不发起新距离测量，返回先前有效距离及角度测量结果；调用可直接进行角度/倾斜测量，Mode 控制倾斜测量或计算，不宣称完全被动。无有效距离时可能只有角值；必须按质量返回码处理。暂不接入生产。 |
| TMC_DoMeasure | 2008 | 139 | 发起或控制测距，不返回距离值。属于控制能力，不能隐藏在读取接口内。 |

第 130 页返回码 1283 表示改正不完整、1284 表示精度不能保证；1285/1288/1289 等不能当作完整有效的距离观测。保留原始结果及质量状态，不用零距离、旧距离或统一 success 代替缺失值。第 125 页的测量程序含启动、停止、清除和红激光跟踪；本研究没有执行其中任何命令。

## 可执行验收合同

1. 先做不接串口的版本化帧解析与身份响应 fixture，覆盖分片/粘包、终止符、超长、未知字段/码、非有限数值、事务不匹配及晚到帧。fixture 标记 synthetic，不能称为实测。
2. 原始字节先持久化并计算摘要，再产生派生记录；固定合同包括设备型号/固件、会话、RPC、参数、通信码、RPC 码、原始单位/值、明确时基、解析器版本和状态。缺少专业元数据时只保存候选数据。
3. 只有确认型号/固件与许可后才打开物理连接，先验证上述身份命令。写入、清除、马达、自动照准、测距和激光能力独立授权，不能通过任意 `sendCommand` 对外提供。
4. 用真实仪器做断连、半帧、超时和重启复验，并与独立仪器输出或厂商软件比较；这一步的设备、现场条件、坐标/高程基准、仪器/棱镜高和数值依据尚缺。模拟测试不能替代它。

完整 GeoCOM 生产接入仍受总计划 P0 验收门禁约束。GSI 文件解析与 GeoCOM 实时 RPC 分开，不把已有 GSI 样本当成串口联调证据。
