## 数学定义与独立依据

`C` 是完整、已知先验、绝对观测协方差；固定 A 满列秩，C 对称正定。记 `W=C^-1`、`N=AᵀWA`、`xhat=N^-1 AᵀWy`，**残差 v=y-Axhat，为观测减平差值**：

```text
Cvv = C - A N^-1 Aᵀ
M = W Cvv W
w(c) = cᵀWv / sqrt(cᵀMc)
```

独立 Python 使用精确有理数 GLS、矩阵逆和二次型，w 以 70 位 Decimal 输出。没有借用产品 QR、白化、条件检查或共享矩阵核。

相关协方差解析例：`A=ones(3,1)`、`y=[0,11,2]`、`C=[[4,1,0],[1,9,0],[0,0,1]]`。独立结果为 `xhat=103/46`，三个观测轴方向的 w 为：

```text
[-19/sqrt(115), 49/sqrt(230), -sqrt(11/46)]
≈ [-1.7717591356565962, 3.2309643196393563, -0.48900964692182576]
```

另一个 4 观测、2 参数的相关 C 模型用于同时行排序（A/y/C/c）、参数列换序、漏排 c 的负对照、c 反号/正比例、两种一致单位变换、混合行单位变换、C 单独乘 9、y/c 加模型空间分量。单独 C 乘 9 时 w 除以 3，不能误认为绝对先验尺度不影响统计量。非零 c 位于 col(A) 时不可探测；本产品合同提前拒绝全零 c，解析生成器保留该数学边界，但不会用它调用产品核。

方法出处沿用已有 AMIRI-2007 式 (2.39) 资料登记；本次数值复审没有把独立推导冒称重新核读该式原文，也未使用论文舍入表值生成高精度期望。

- 9 个非零次正规数协方差边界均返回 `numeric-range-or-backward-error`；18 个巨大模型均值配合正常/极小先验的组合也全部返回明确不可用。

这些固定算例不证明任意输入的误差上界，也不是统计分布覆盖率试验。

## 原缺陷及修复边界

取 `A=ones(2,1)`、`s=3*Number.MIN_VALUE`、`C=s*I`、`y=[0,sqrt(s)]`、`c=e1`。解析 `Cvv/s` 必须为 `[[.5,-.5],[-.5,.5]]`。旧实现却返回 resolved，`Cvv/s=[[1/3,-2/3],[-2/3,2/3]]`，行列式为 `-2/9`，已经不定；w 本身仍约为正确的 -0.7071。

原因是原检查只覆盖非零结果完全下溢成零，未覆盖仍非零的次正规数严重相对舍入。修复后对非零次正规数 Cov(v) 元素或残差能量保守返回不可用，同时保留完全下溢检查。`boundaries.json` 中的旧值明确标注为从修复前探针工具输出转录，未伪称本包重新执行了旧源码。当前源码上的真实复测记录在 `summary.json`。
