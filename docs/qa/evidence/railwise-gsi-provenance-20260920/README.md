# GSI 历史转换来源补充核查

日期：2026-09-20。状态：`historical-intermediate-value-chain-aligned-rounding-provenance-unresolved`。`professionalApproval=false`，`releaseApproval=false`。

本次发现并验证了此前未纳入核查的 HDF 逐站表和 GCO 往返统计表。14/14 条 IN1 路线高差都能由 HDF 中对应的已打印逐站高差精确相加得到；28/28 个测站的四次原始尺读数与 GSI 完全一致。此前 7 条不一致路线已有中间文件数值对应，但原转换程序的内部舍入规则和可认证的执行记录仍未找到，不能改为“来源完全闭合”。

## 新增实测证据

| 检查 | 结果 | 含义与边界 |
| --- | --- | --- |
| 同名历史资料副本 | 5 处的 7 类文件分别具有相同 SHA-256 | 是相同字节的重复保存，不是 5 份独立专业证明 |
| GSI 与 HDF 测站对应 | 28/28 起讫点及顺序一致 | 仅归一化大小写及产品内部转点命名空间，没有合并、替换实际点名 |
| GSI 与 HDF 原始尺读数 | 28 站、每站 4 次，共 112/112 值精确一致 | 使用十进制数值比较，没有产品平差内核参与 |
| 两次高差均值 | 28/28 精确一致 | 按 `(B1-F1+B2-F2)/2` 从四次原始读数独立计算 |
| HDF 已打印测站高差汇总至 IN1 | 14/14 路线精确一致 | 按起讫点和原观测顺序连接测站，没有依赖单纯每两行凑组 |
| GCO 与 IN1 | 7/7 往返组、14/14 高差精确一致 | GCO 起讫方向与 IN1 首路线方向相反，按实际端点对齐后比较，未改正负号原件 |
| 原来超过半打印单位的 7 条高差 | 7/7 均有上述 HDF 逐站合计对应 | 解释了当前 IN1 数值与哪一份历史中间结果相同，不证明实际生成顺序和作者 |
| 检查前后原件 | 所有读取的原件字节相同 | 没有修改 GSI、HDF、IN1、GCO 或其他原件 |

HDF 的“测站高差”保留 5 位小数，单位为米。28 个打印值均位于精确原始均值的半个打印单位内；11 个恰好相等，17 个处于 `0.005 mm` 的半单位边界。该半单位属于表示精度，不是工程规范允许误差。

这些是明确规则的诊断试验，不是对历史软件实现的认定。当前不能证明原程序采用哪种内部数值表示、运算次序、舍入时点或半单位处理，也不能把失败的 3 个 HALF_UP 测站归因于人工修改。未尝试通过逐站选择不同规则来拟合原结果。

## 资料中的缺口

同目录 BM1 和 Gci 均为空文件。统计 DOC 中网名、等级、测量单位、测量时间、测量人员、仪器和网型字段均有标签但为空；HDF、GCO 和 DOC 中未找到明确的软件版本、转换说明、改正或舍入设置。上述结论限于本次读取的文件集合，不能推断其他存储位置不存在相关资料。

仍需以下原始证据才能关闭剩余来源问题：

1. 原转换软件的名称、完整版本或构建号，以及可核验的程序或配置。
2. 该版本对 BFFB 原始读数的运算次序、内部精度、输出位数和半单位舍入规则。
3. 关联这组 GSI、HDF、GCO、IN1 文件摘要的实际逐站转换或导出日志。
4. 仪器改正、尺长温度等设置及人工编辑记录，并由资料责任人确认；不能由 AI 推断代替。
