# 质量证据工作区与规范抽样增量

本模块是技术证据保全，不是 GB/T 24356-2023 完整质量验收。它不认证人员、不评分、不签字、不批准成果，也不代替 Survey 数值重算和源文件准入检查。原有复验功能继续单独提供后两项能力。实施依据及剩余生产层次见[接入审计](RAILWISE_SURVEY_QUALITY_INTEGRATION_AUDIT.md)。

## 证据工作区

在待审清单旁展开证据保全，阅读本次成果文件及各自摘要后明确确认，冻结不可修改的计划。计划保存项目修订、manifest、实际文件集合及每项要求对应的确切成员；不会把另一个文件当成已要求的文件。每次后续计划都是新记录，不静默修改历史。

用户另行创建检查记录，按项执行字节完整性检查或留存指定成员。服务端决定检查结果和system身份，请求不能填写通过状态、真人身份或删减必检列表。所有输出文件及原始manifest保留，独立质检数据库只追加证据。

- 本地认证、项目/清单/计划/成果包/成员绑定。
- SQLite 追加保护、同链尾比较、载荷绑定幂等；读取重核行身份、链、原文件和保留字节。
- 失效或损坏的历史条目显示具体不可恢复状态，不阻断同页有效条目；原详情仍严格拒绝。
- 文件限定在本项目成果目录，拒绝符号链接、特殊文件、读时替换、越界及超限；每文件32MiB、每包128MiB。同步磁盘读取具有字节上限，不声称具有墙钟超时保证。
- 本地链和摘要不等于独立保管；`coverageStatus`、`standardConformity`、`humanSignatureVerification` 仍为 `not-evaluated`。

认证API位于 `/v1/engineering/projects/:projectId/quality-plans`、`quality-evidence`、`quality-records` 及其详情/checks/verify。桌面 IPC 同样限制方法、请求合同与分页。旧 monitoring 质量页保留，本增量不改已有数据或 reviewStatus。

## 独立抽样纯内核

[抽样内核](../../kun/src/engineering/survey-quality-sampling.ts)绑定官方 GB/T 24356-2023 PDF、表1页面、完整16区间及其哈希。它显式接收单位成果定义、总体、阶段、检查方式与随机来源，禁止从原始观测数推断单位成果。过程检查及最终内业强制全数；允许抽样时执行表1与1001及以上的最少均匀分批规则。

无放回选择采用有版本的 HMAC-SHA256、uint32拒绝取模偏差和部分Fisher-Yates，保留种子声明、总体顺序及完整结果哈希。这是可复现的软件选择，不是规范指定算法，也不认证种子随机性、空间均匀性、总体完整性或前轮检查。数学精度恰为20的规范歧义、完整错漏评分、人员授权、独立签认及交付批准不在此增量内。抽样纯核尚未接入工作区 Runtime 或 GUI，不能把纯核存在描述为已完成生产抽检流程。
