## 打包门禁

1. `npm run verify:specialist-skills` 会重新计算全部文件哈希，并检查当前资产树与固定提交一致。
2. `beforePack` 在任何安装包构建前强制执行同一检查；清单缺失、哈希变化或固定提交不可解析会直接阻断打包。
3. Agent Pack 安装器只安装 `status=available && packaged=true` 的 Skill；缺少审计记录也按阻断处理。
4. Electron 资源过滤器会把被阻断 Skill 同时从 Agent Pack 和顶层兼容 Skill 路径排除。
5. 被阻断或移出 catalog 的项目只清理 WorkWise 自己管理的旧副本；同名用户 Skill 继续触发冲突保护，不覆盖、不删除。

## 场景证据

场景覆盖工程测量平差、平差报告、地保监测、建设期第三方监测、运营期监测、监测方案、招投标、规范检索、DOCX/XLSX、图表、成果写作，以及 Agent Pack 中保留的审批、经营、客户门户、知识整理、资源调度和周报能力。每个场景的实际提示、期望证据文字和测试编号均已写入 provenance 清单；测试文件为 `kun/src/engineering/specialist-skill-provenance.test.ts`。

本审计只证明来源、再分发、静态权限、依赖声明和 SkillRuntime 场景加载满足打包门槛，不把模型生成文字当作测量数值验证。控制网、坐标转换和变形分析仍以 WorkWise Runtime 确定性数值内核及独立 golden fixture 为准。
