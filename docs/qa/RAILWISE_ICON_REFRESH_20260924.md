| 位置 | 行为 |
| --- | --- |
| macOS 运行中 Dock | 程序码在启动时依据系统明暗主题选择，并监听主题变化；实际 Dock 切换尚未在本轮 GUI 中确认 |
| macOS Finder、未运行的应用、DMG | 浅色静态 ICNS。实际 Finder 已显示新浅色图标；没有声明支持系统 Icon Composer 的 Dark/Tinted 图标选择 |
| Windows EXE、安装器、快捷方式、窗口/托盘 | 固定右侧深色 ICO/PNG；不依赖 Explorer 自动选择主题图标 |
| 应用内会话活动标识 | 跟随应用主题切换浅色/深色 PNG |
| 启动窗口 | 跟随系统主题切换，含显示期间主题变化 |
| Linux | 静态深色 PNG |
