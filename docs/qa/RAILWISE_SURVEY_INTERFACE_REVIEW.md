# Survey 外业接口、MCP 与跨工作台预审

日期：2026-09-19。性质：用户授权的智能体模拟专业预审，基于源码、既有测试和已落库来源记录。它不是仪器厂商认证、持证专业人员签字、真实外业联调或用户安装包验收。本次未连接、转动、测距或配置任何真实仪器。

2026-09-20 补充：[GeoCOM 厂商手册核查](./evidence/railwise-field-interface-20260920/README.md)已取得 ETH 保存的 TPS1200 Version 1.10 全文并核对协议、单位、RPC 与质量返回码；补齐的是限定版本资料，不是当前型号/固件、许可或仪器联调。本页以下内容保留 09-19 的实现与研究边界。

## 本次可独立落地的增量

新增 `kun/src/adapters/mcp/survey-context-reader.ts`，为待接线的、与传输无关的只读边界，未注册 MCP 服务、未监听端口、未修改现有配置或旧别名。

- 输入仅接受 `projectId` 及可选的 `expectedProjectRevision`、`expectedContextHash`；拒绝路径、写操作、客户端自授项目列表及未知字段。
- 宿主必须将 `canReadProject` 绑定到已认证客户端的授权记录；先检查权限再读存储，每次请求重新检查，读取后再次检查。不得用 `() => true` 接入外部客户端。
- 检查返回项目一致性和可选版本/hash 条件；失败返回稳定错误，不转发存储路径。
- 固定投影只返回项目 ID/版本/hash、时间、网络计数、平差 ID/算法版本/输入 hash、当前来源准入。排除项目名、任务文本、坐标、原始观测、路径、规范摘要和诊断文本；未来增加的内部字段不会自动外泄。
- 返回标记 `read-only-summary`、`context-metadata-only`、`untrusted: true`；最多各 20 个网络/平差，64 KiB 响应上限，并明确这是有界快照，不是完整项目清单。
- 不将历史成功结果冒充当前可用来源：根据当前完整性和来源资格重新计算准入状态。此状态也不是成果文件复验通过的证明。

测试覆盖未授权不读存储、权限撤回、非法字段/伪造授权、跨项目回包、旧版本/旧上下文、敏感字段与未来字段不泄漏、不修改源对象、来源失效降级、存储错误隐藏、集合/响应界限。七项定向测试通过。该模块是权限适配基础，**不是完整对外 MCP 已交付**。

随后新增可嵌入的 `survey-context-server.ts`：使用仓库已安装的 `@modelcontextprotocol/sdk`，注册 `survey_context_read`，输入共用 reader 的 strict schema。宿主为每个认证会话单独创建 server，注入 `principalId`、实时 `canReadProject(principalId, projectId)` 与快照读取；没有身份或授权回调时默认拒绝全部项目。MCP 客户端初始化的名称、请求参数以及客户端传入的授权数据均不能作为身份来源。异常由固定白名单错误码输出，宿主权限/存储异常不会带出路径和凭据。

`survey-context-server.test.ts` 通过 SDK `InMemoryTransport.createLinkedPair()` 连接真实 SDK `Client` 与该 server，实际完成初始化、`tools/list`、`tools/call`，验证唯一只读工具、成功读取、字段脱敏、跨项目拒绝、同一连接撤销权限、伪造身份拒绝、stale/错项目回包、授权/存储异常隐藏。七项协议测试通过，连同 reader 共 14 项；Runtime typecheck、目标 ESLint 通过。这里运行的是进程内的真实 MCP 消息协议测试，不是公网传输、桌面 MCP 配置或第三方应用端到端验收。

factory 不开启端口、不启动子进程、不读取全局 Runtime token、不改用户 MCP 配置和旧路由。没有增加虚构的 stdio 启动参数来默认授权所有项目。宿主接入仍需提供认证身份与可撤回项目授权的持久化/配置界面及生命周期管理。

### 2026-09-19 独立复审增量

复审发现并修复两处运行时边界缺陷：

- 授权回调原先按真值判断，JavaScript 宿主误传对象、字符串或异步 `Promise<boolean>` 会被当成授权成功。reader 与 factory 现在均仅接受字面布尔值 `true`；当前接口为同步授权合同，异步回调被拒绝，不会读取项目存储。reader 也对授权异常输出固定错误码。
- 投影仅依赖 TypeScript 类型，宿主或存储返回的异常字段可能是含私密属性的对象，且 `JSON.stringify` 可执行其 `toJSON`。现在在序列化之前以严格 schema 校验外发投影，拒绝对象元数据、非有限数值、负计数和无效版本。只序列化通过校验后得到的数据。

新增 reader 与 SDK Client 回归覆盖非布尔授权、授权异常、对象字段及 `toJSON` 不执行、无效计数/版本、读取过程中撤权和异常输出脱敏。当前 reader 9 项、server 9 项，共 **18 项通过**；`npm run typecheck`（`kun`）、目标 ESLint 与 `git diff --check` 均通过。测试仍使用进程内 SDK 传输，未扩大为第三方客户端、真实 stdio、真实外业或专业签字验收的结论。

## 对外 MCP 接线合同

以下合同中的 SDK 工具注册与进程内客户端调用已完成，桌面宿主及真实第三方客户端接入尚未完成。工具名为 `survey_context_read`；输入/输出使用本模块，不直接暴露 Runtime 快照或任意 REST 代理。

| 项目 | 必须满足的边界 | 验收证据 |
| --- | --- | --- |
| 传输/版本 | 优先本机 stdio；远端启用前单独验证当期 MCP 传输、认证和版本协商，不自行宣称合规 | 固定 SDK/协议版本；初始化、关闭、取消、错误与重连的客户端记录 |
| 授权 | 客户端身份→项目白名单→能力；默认无项目、无写权限；撤回立即生效 | 客户端 A 不能读取 B 项目；省略项目、换 ID、猜测 ID 均不泄漏 |
| 数据范围 | 摘要权限与原始记录/成果文件权限分离；原始数据另行显式授权 | 外部响应字段审计、日志脱敏、没有绝对路径/密钥/坐标样本 |
| 写能力 | 初期完全不提供；以后写操作必须经过现有 Typed Plan、参数摘要、风险、预期产物、可逆性、审批和幂等性 | 伪造批准、旧 contextHash、旧 revision、重放与跨项目请求拒绝 |
| 错误 | 固定错误类别，无本地路径、请求密钥或数据摘要；客户端不得据失败猜测项目存在 | 权限错误、未知 ID、存储异常三类负向记录 |
| 兼容 | 保留旧插件、MCP 和凭据引用；新能力默认不自动授权 | 迁移矩阵和真实用户数据演练 |

## 外业适配方案与待核实协议

采用单一 Runtime 的端口/适配器扩展，拟置于 `kun/src/ports/` 与 `kun/src/adapters/`；不得增加第二个运行时。数据流为：设备传输→原始字节留存→帧/命令关联→单位与时间解释→质量校核→候选观测批次→人工接纳→现有 Survey 导入。传输成功、设备返回成功码、格式有效和专业可用四种状态必须分开。

仪器厂商/型号/固件和授权状态均未确认，因此本报告不填写未经核实的 GeoCOM RPC 编号、波特率、校验位、角度单位或错误码。正式适配前必须获取有版本的厂商接口手册/授权信息，并用设备响应核对这些值；开源库只能作为实现参考。

| 协议/来源 | 当前能做的工作 | 尚缺证据 |
| --- | --- | --- |
| Leica GeoCOM（传输方式由型号/手册决定） | 整理身份读取、状态读取、已有观测读取的白名单；模拟传输与错误注入设计 | 厂商版本手册、具体型号/固件、接口许可、真实设备读操作记录 |
| GSI 文件导入 | 复用既有严格 lexer、单位解释、原始锚点与来源资格门禁 | 新方言须独立 golden/negative；不得靠放宽 lexer 接入未知设备 |
| GNSS NMEA/RTCM/RINEX | 划分实时位置/差分/离线观测三类；记录消息版本与时间系统 | 具体版本官方材料、接收机型号、质量字段、独立基准，未新增生产解析器 |
| 厂商文件/云 API | 先冻结字段、单位、坐标参考、分页/重试与授权合同 | 真实接口说明、可再分发样本、最小权限账号、对照成果 |

初期读操作也必须明确区分“读取已有测量值”与“触发测量”：触发测距、目标搜索、自动照准、马达运动、放样指令、激光/补偿器配置和写入仪器存储均视为控制能力，不能通过一个通用 `sendCommand` 暴露给模型或普通 Flow 节点。

## 联调与失败注入矩阵

| 主题 | 校验计划 | 不可省略的成功条件 |
| --- | --- | --- |
| 设备身份 | 连接/重连读取型号、固件、序列号；会话绑定设备 ID | 换机、固件能力不符时停止接纳，原会话不混入新机数据 |
| 断连/超时 | 分别在发命令前、发出后、半帧、回包后断开；注入忙/超时/取消 | 已发控制命令状态不明时不得盲目重发；标记 unknown，人工核对；不伪造零值或上一条值 |
| 帧边界 | 分片、粘包、超长帧、乱码、未知字段/返回码、关联号不符、晚到回包 | 原始字节保留；只将完整且关联一致的帧提升为候选观测 |
| 单位 | 角度 rad/deg/gon 与 D.MMSS 分开；长度/距离/高差/温压各自显式单位 | 无元数据拒绝自动猜测；保留原值及单位、转换版本；角度非法分秒不归一化掩盖 |
| 坐标/高程 | 验证轴序、参考框架/历元、投影、垂直基准、仪器高/棱镜高及常数 | 信息不全只留原始记录，不可生成可平差网；不把椭球高当正常高 |
| 时间 | 同时保留设备时间文本/时间系统、接收 UTC、单调时钟与序号；测试无时区和时钟回拨 | GPS/UTC/本地时间转换有版本证据；缺失/不确定标记，不用到达时间替换测量历元 |
| 幂等性 | 同帧重复、同测站同历元不同值、断点续传、进程重启；故意重复提交批次 | 会话 ID+设备序号+原始内容 hash 去重；真正重复测量保留独立记录；无设备序号时不单凭数值去重 |
| 原始记录 | 入库前哈希原始字节；记录传输/设备/解析器版本；注入截断、修改和顺序错乱 | 只追加记录；不修改原字节；派生更正另外记录、重放可复核；hash 不冒充数字签名 |
| 队列/存储 | 下游变慢、磁盘满、权限拒绝、数据库事务失败、关闭中断 | 未持久化不能 ACK 为接纳；有界队列与丢失计数，无静默丢帧 |
| 专业对照 | 同一物理基准用独立仪器输出/厂商软件/可信计算建立对照 | 保存设备、条件、参考成果和误差依据；模拟器通过不能代替真实联调 |

## Survey / Write / Design / Flow 的证据联动

统一传递不可变引用：`projectId + projectRevision + contextHash + networkId/revision + adjustmentId + inputHash + manifestId/outputSha256`，并携带来源当前准入和草稿/已审状态。显示文本可修改，证据引用不得被生成式文本覆盖。

- Write 引用确定性结果和成果 manifest；重新编辑正文后产生新的草稿版本，引用原成果的 hash 不意味着编辑后文件仍已验证。
- Design 读取选定结果做图，不改变原始点位/坐标；图例必须注明单位、基准、比例或非等比例示意。点云/DXF 扩展继续受原计划门禁约束。
- Flow 以 Typed Plan 调用既有服务，并持有项目版本与操作幂等键；等待审批期间输入发生变化则计划失效。取消/重试不能重复导出或归档。
- `http`、通用 `pdf_output` 等节点不能冒充 Survey 成果交付步骤。现有通用 PDF 输出有字符/页长限制，Survey 报告必须走已有专业导出与 manifest 复验。
- 验收至少包括项目 A→B 切换、等待审批后输入修改、导出后篡改、一次操作重复触发、取消后重启、旧工程恢复、来源失效后历史成果仍可读但不能用于新交付。

## 本次结论与剩余项

模拟接口审查完成，并交付只读上下文适配、可嵌入 MCP SDK server factory 及协议测试。当前不批准把通用 Survey 服务、仪器控制或 Runtime Bearer 直接暴露给外部客户端。

完整 P2 仍缺：MCP 桌面宿主身份/项目授权配置与真实 stdio 或远端传输、第三方客户端互操作、Write/Design/Flow 上述证据接线及端到端验收、厂商协议材料和设备许可、真实仪器失败注入及数值对照。外业、点云和长尾格式生产扩展依原计划在 P0 与候选包验收后进入；研究、合同和纯只读适配可先行。没有将这些剩余项标记完成，也没有将智能体预审替代用户本人 UI/功能确认或专业签名。
