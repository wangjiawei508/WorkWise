# P0 格式准入验收记录模板

> 本模板用于记录一个 P0 格式从研究、结构识别到可进入私有候选包验收的证据。它不是格式规范、授权书或发布批准。空白项、无法核验项和范围不明确项均视为未满足，格式必须保持 `archive-only`。

| --- | --- |
| 记录编号 | `P0-FMT-...` |
| 格式 / 版本 / 方言 | |
| 对应目录注册表 ID | |
| 目标网络策略 | |
| 记录日期 / 负责人 | |
| 技术复核人 / 测绘复核人 | |
| 当前处置 | `archive-only` / 其他（仅满足全部门槛后填写） |
| 本次决策 | 保持阻断 / 允许私有候选验证 / 提议更新目录 |

## 2. 来源、授权与数据边界

| 核验项 | 证据位置或结论 |
| --- | --- |
| 提供方及有权授权主体 | |
| 书面授权标识、日期和有效期 | |
| 允许用途 | 内部测试 / 私有候选包 / 私有化交付 / 公开再分发，逐项填写 |
| 再分发、署名、保密和删除要求 | |
| 真实/脱敏状态及脱敏责任方 | |
| 是否含项目、客户、坐标、仪器序列号或个人信息 | |
| 数据最小化与隔离位置 | |
| 许可证/使用条款原文保存位置与 SHA-256 | |
| 法务/数据负责人确认 | |

未取得有权主体的书面边界时，不得下载、复制、加入 fixture、放入候选包或改变格式处置。

## 4. 语义、单位与基准映射

任何依赖猜测的列序、单位、角度格式、站点角色或基准，必须作为阻断项；不得用默认值制造可平差观测。

## 5. Parser 与安全验证

| 核验项 | 证据位置或结论 |
| --- | --- |
| 检测器、parser、registry 版本和源码提交 | |
| 正常 golden 输入与独立期望来源 | |
| 数值对照的独立计算人/软件/版本 | |
| 负向样本：截断、非法字符、字段缺失、单位冲突、扩展名冲突 | |
| 边界样本：最大记录数、长行、重复点、未知字段、角度进位 | |
| 解压/包装器：CRC、路径、嵌套、大小和记录上限 | |
| 原始记录锚点、诊断和来源哈希断言 | |
| 通过的测试命令、日期和完整输出存放位置 | |
| 未覆盖的方言或风险 | |

golden 和 negative 必须独立于 parser 编写；同一解析实现生成的期望值不能作为唯一验收依据。

## 6. 私有候选包验收

| 核验项 | 证据位置或结论 |
| --- | --- |
| 候选包版本、构建提交、构建时间和 SHA-256 | |
| 签名 / 公证状态 | |
| 安装环境、架构和操作系统版本 | |
| 导入预检截图：检测、哈希、单位、基准、处置、诊断 | |
| `archive-only` / `gnss-processing-required` / `converter-required` 阻断截图 | |
| 已授权且完整样本的导入、确认、校核、平差和成果包截图 | |
| DOCX、PDF、XLSX、manifest 中的来源和单位追溯核验 | |
| UI 键盘与窄窗/主题验收 | |
| 实机复核人和结论 | |

候选包证据只能使用授权范围内的样本和隔离的私有 feed。它不构成公开版本、Git tag、Release、stable/frontier feed 或下载页的授权。

只有上表每一项均为“是”，才可以提出更新 `survey-format-catalog.ts` 的独立变更。更新前仍须复核该格式的适用网络策略；不满足策略所需观测时，导入仍必须阻断，不能以格式已准入为由绕过网络校核。
