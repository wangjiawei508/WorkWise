# WorkWise 0.3.6 候选说明

0.3.6 是从当前正式 stable `v0.3.5` 继续开发的下一个补丁候选版本。它聚焦应用内更新、精选插件市场、本地 Skill 边界和界面可读性修复。

## 关键修复

- 更新失败按未签名构建、清单、网络、签名、下载和安装错误分类，不再把自动更新失败伪装成官网跳转。
- 插件市场只展示 11 个精选插件，按用户任务分类；本地 Skill 保留在独立技能页，不混入精选市场。
- 插件详情补齐产品类型、实现方式、权限、认证、许可证、来源、依赖和健康状态。
- 保留旧插件配置、Skill、凭据引用和迁移兼容，不静默删除用户数据。
- 侧边栏恢复实色高对比背景；玻璃效果仅用于启动窗口、标题栏和临时浮层。

## 版本路线

- `v0.4.0` 已撤回且没有实际下载用户，不为它保留降级或 `0.4.1` 升级桥接。
- `v0.4.0` 标签、Release 和安装资产仍保留供审计，并继续从 stable 候选中排除。
- 0.3.6 当前仅为待验收候选版本。未获得界面、功能、准确版本号和发布动作的明确批准前，不得创建标签、GitHub Release、推广 stable 或更新官网。

## 已有验证证据

- 同一功能代码基线的 TypeScript、ESLint、生产构建、ASAR 一致性和 Quality CI 已通过。
- 先前的内部 `0.4.1` 签名产物已在 macOS arm64/x64 和 Windows x64 上完成真实应用内更新闭环。这些记录仅作为更新机制的历史证据，不是 0.3.6 产物验收。
- 内部 `0.4.1` 候选的中文启动页、主界面、精选市场、详情抽屉、独立 Skill 页面和运行时连接截图仅用于回归对比。

## 0.3.6 发布前必须重做

- 基于最终 `0.3.6` 提交生成三平台签名候选产物。
- 重做真实 `0.3.5 -> 私有 0.3.6 候选` 应用内下载、退出安装、自动重启和用户数据保留闭环。
- 重做中文界面、深浅主题、窄窗口、降低透明度和 GPU 回退验收。
- 更新清单服务器仍返回七天缓存响应头；正式发布前仍需修复基础设施配置或由用户明确接受该残余风险。
