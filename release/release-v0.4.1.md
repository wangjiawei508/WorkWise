# WorkWise 0.4.1

0.4.1 是 0.4.0 的修复版本，恢复插件市场安装与应用内更新两条核心交付链路。

## 修复内容

- 修复从 Finder 等图形界面启动 WorkWise 时没有继承交互式 Shell `PATH`，导致插件市场调用不到 `npm` 或 `git` 的问题。
- 插件下载子进程现在继承补全后的执行环境，并识别系统路径、Homebrew、npm 全局目录、Volta、asdf、Bun 和 NVM 等常见用户工具目录。
- npm 直连安装、GitHub Skill 固定提交下载和通用 Git 目录同步统一使用同一套命令解析逻辑，避免只修复单一插件类型。
- 取消客户端对 0.4.0 的内置“已撤回”判定；只有显式设置撤回版本配置时才会阻止对应版本继续更新。
- 补充 DeepSeek Harness 接入说明，如实记录 WorkWise 实际使用的适配器、结构化附件和本机视觉证据边界。

## 兼容性

- 不删除、不替换或迁移现有插件、MCP 配置、Skill、凭据引用和用户数据。
- 保持正式应用 ID、更新源和 0.4.0 用户数据目录不变，支持从 0.4.0 原位升级。
- 不修改 OpenAI Official 或第三方 API 配置。

## 验证范围

- 命令解析覆盖继承路径、GUI 最小路径、不可执行文件回退、Windows `Path` / `PATHEXT` 和 Node shebang。
- 插件安装覆盖 npm 直连、GitHub Skill、通用 Git 目录和受管 PyPI 错误路径。
- 自动化验证通过：282 个测试文件通过、2 个跳过；2310 项测试通过、2 项跳过；TypeScript、ESLint 和生产构建通过。
- 正式发布前必须完成签名与 Apple 公证校验、安装后界面检查、插件真实安装和 0.4.0 到 0.4.1 的隔离更新源往返。
