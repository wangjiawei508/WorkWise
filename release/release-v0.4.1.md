# WorkWise 0.4.1

0.4.1 是 0.4.0 的修复版本，重点解决错误 0.4.0 的应用内升级、精选插件市场展示和本地 Skill 边界问题。

## 关键修复

- 已安装错误 0.4.0 的用户可通过应用内更新升级到 0.4.1。
- 0.4.0 标记为撤回版本，不再作为 stable 更新候选；0.4.1 作为当前 stable 修复版本。
- 更新失败按未签名构建、清单、网络、签名、下载和安装错误分类，不再把自动更新失败伪装成官网跳转。
- 插件市场只展示 11 个精选插件，按用户任务分类；本地 Skill 保留在独立技能页，不混入精选市场。
- 插件详情补齐产品类型、实现方式、权限、认证、许可证、来源、依赖和健康状态。
- 保留旧插件配置、Skill、凭据引用和迁移兼容，不静默删除用户数据。

## 验证

- TypeScript、ESLint、生产构建和 ASAR 一致性检查通过。
- Vitest：246 个测试文件通过、2 个跳过；1767 项测试通过、2 个跳过。
- macOS arm64 候选包已完成中文界面、筛选、详情和独立 Skill 页面验收。
- 正式发布前由 GitHub Actions 生成 Developer ID 签名、公证的 macOS 包和 Windows 安装包，并完成真实 0.4.0 -> 0.4.1 更新闭环。

## 升级说明

- 0.4.0 用户应通过应用内更新升级到 0.4.1；若当前安装包没有签名或公证，需先手动安装正式签名版本。
- 第三方插件自动更新默认关闭；权限、许可证、脚本或网络域变化必须重新审查。
- 公共投稿市场不属于 0.4.1，后续单独立项。
