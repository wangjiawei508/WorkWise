# WorkWise 0.3.3

0.3.3 以 WorkWise Flow Preview 为主线，并把通用文档附件和应用内更新作为稳定版发布硬门槛。应用、内置 Runtime、安装包与更新清单统一使用 0.3.3 版本。

## 本版范围

- 默认可见的 Flow Preview 工作台、类型化节点、持久化执行与定时任务迁移。
- 对话支持 PDF、DOCX、XLSX、PPTX、TXT、Markdown、CSV 和 PNG/JPEG/WebP；长文档在本地解析并按需检索。
- 正式包使用 `railwise.cn` Stable/Frontier 更新源，后台下载后由用户选择“重启并更新”。

## 使用要点

- 输入框加号已改为“添加文件或图片”。文档解析完成后才可发送；百页招标 PDF 通过本地分段检索按需读取，并返回页码、工作表或幻灯片来源，不直传全文。
- 定时任务首次启动时迁移为定时 Flow，原设置保留一个版本的只读备份。未配置飞书、微信、生成模型或外部 CLI 时，对应节点会显示禁用原因和配置入口。
- 更新首次点击只下载；完成后再次点击“重启并更新”。应用会先保存 Write、Design 等编辑内容并列出活动 Agent、Flow 和定时工作，确认后建立检查点、停止 Runtime、自动安装并重新启动，全程不打开浏览器。

## 兼容说明

公开 0.3.2 未内置签名后的正式更新链路，因此 0.3.2 用户需要最后一次手动安装已签名、公证的 0.3.3。自 0.3.3 起，后续正式版本使用应用内更新。

Flow 仍标记为 Preview；文档附件与应用内更新按稳定能力验收。缺少 R2、自定义域名、Apple Developer ID、公证凭据或目标平台验收证据时，不得提升 Stable。
