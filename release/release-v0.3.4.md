# WorkWise 0.3.4

0.3.4 是针对 0.3.3 的紧急纠错正式版。由于应用内更新只接受严格递增的 `x.y.z` 版本，不能用同名 0.3.3 工件覆盖已安装客户端；本版使用 0.3.4 让现有用户能够收到并安装修复。

## 关键修复

- 明确 Code、Write、Design、Flow 与定时任务的工作区边界；Design 和 Flow 不再显示 Code 项目会话，“新建需求”移动到 Write。
- 定时任务恢复独立列表和编辑器，并提供显式“查看定时 Flow”入口，不再点击后静默跳到 Flow。
- Design 为每个设计文档创建独立 Agent 会话，显示完整时间线和当前 AI 修改目标；修复右侧栏反复卸载导致的 React #185 更新循环。
- PPTX 改为本地“可读优先”导入：自包含 SVG 在隔离、禁网的 Electron 渲染器中转为整页视觉参考；提高仍受总量、压缩率保护的 OOXML 单部件上限，错误不再暴露内部代码。
- Write 助手扩大可用宽度，恢复 PDF、DOCX、XLSX、PPTX、TXT、Markdown、CSV 和图片附件入口、解析状态、重试、取消、打开和移除。
- Write 新增“编制投标文件”入口，调用内置 Tender Master，按附件来源解析评分办法、实质性要求和格式约束后逐章编制。
- Flow 新建即生成“手动触发 → Agent”的可运行起始图，保留节点配置、Mock/单节点测试、发布校验、运行历史、审批和失败恢复。

## 兼容与更新

已安装 0.3.3 的用户可通过顶部蓝色更新入口下载，并在完成后点击“重启并更新”。0.3.2 及更早版本仍需先手动安装带正式签名和公证的版本。原计划的 Extension 开放平台与 DeepSeek V4 深度适配顺延至 0.3.5。
